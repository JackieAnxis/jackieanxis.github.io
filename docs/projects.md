# 项目

这里是我在工作和开源中参与的主要项目。

## 华为云

### OfficeClaw — 企业级泛办公智能体

面向内容生成、文件处理、知识搜索、PPT 制作等高频办公场景的企业级智能体产品。负责 AI PPT 生成的核心算法设计和多 Agent 协同优化。

### DataArts Insight — 数据智能体

华为云新一代企业级智能分析平台，支持通过自然语言完成数据查询、图表生成和业务洞察。负责数据智能体核心算法设计和企业场景落地，已在中国工商银行、南京钢铁等企业落地应用。

### 模型创新平台

高可定制 + 低开发门槛的 Code-based Agent 编排平台，从 0-1 构建并完成 POC。

## 开源

### llm-for-everyone

面向所有程序员的大语言模型入门教程，从神经网络基础到 Transformer 推理与预训练。包含 JavaScript 实现的交互式小型 Transformer（tinymind.js）。

### minimind

超小语言模型的开源实现（Python），用于教学和实验。
